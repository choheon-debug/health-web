# 건강 레시피 (웹앱)

구글 Gemini AI가 실시간 웹 검색으로 건강 식단·음료·운동, 음식 정보와 레시피, 주변 맛집, 주간 식단을 알려 주는 웹앱입니다. 아이폰·안드로이드 모두 인터넷 주소로 열고 홈 화면에 추가해 씁니다.

- 식단·음료·운동 추천 (질병/고민, 계절, 다음 식사 시간 반영)
- 음식·식재료 검색, 사진으로 찾기, 주변 맛집 찾기(위치 또는 기본 지역)
- 주간 식단 짜기(표), 질문하기, 다시보기(최근 30개)
- 참고한 웹 자료 링크, 내용 복사·보내기

## API 키
코드에는 API 키가 들어 있지 않습니다. 앱의 ⚙ 설정에서 각자 Gemini API 키(https://aistudio.google.com/apikey)를 넣으면 그 휴대폰에만 저장되고, 구글 AI로 바로 요청합니다.
